## About Me

Full-stack developer based in Portugal, focused on building production-ready systems across web, desktop, and mobile with React, Node.js, and TypeScript.

I replaced a 10+ year legacy PHP platform in 6 months as an intern — sole developer, from database schema to production deployment. That system is currently processing ~100 repairs/month for a live team.

Most of my work lives in monorepos. I like sharing typed business logic across platforms and keeping everything consistent from the database layer to the UI.

Currently open to full-stack opportunities in the Porto/Aveiro region or remote within Portugal.
